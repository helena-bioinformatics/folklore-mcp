# Hosted notebook integrations

- `noodle_literature_graph.ipynb` searches biomedical literature and retrieves
  one bounded, typed graph neighborhood.
- `folklore_variant_to_noodle_graph.ipynb` demonstrates the cross-service path
  from public germline variant evidence to source-linked literature discovery.

Both notebooks use only Python's standard library, require no secrets, and run
unchanged in Google Colab or Kaggle. They call the canonical hosted MCP
endpoints and do not duplicate scientific logic.
