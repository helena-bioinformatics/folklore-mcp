# Adoption measurement

Aggregate public MCP measures:

- Discovery and tool-call counts by coarse surface.
- Typed outcome counts: resolved, ambiguous, not_found, invalid_request,
  unsupported and resolution_unavailable.
- Reliability, latency and technical error-rate distributions.
- Coarse referral/directory source supplied independently of user identity.

The aggregate event projection excludes scientific inputs/results, IP addresses,
user-agent strings, cookies, fingerprints, account identities and full URLs.

## Team contact

<https://folklore.helena.bio/integrations#introduce-team> is a separate,
user-submitted form. Fields: self-reported organization, work email, interest,
optional message and explicit contact permission. Submission goes to
`contact@helena.bio` for a relevant reply. Anonymous tool-use events and form
submissions have separate data flows.
