# Methods review

Clinical genetics, molecular genetics, bioinformatics and reproducibility
reviewers can examine the public comparison protocol and propose falsifiable
corrections or acceptance criteria.

Review sampling/stratification, allele identity and assembly handling, class and
criterion definitions, source coverage, missing outcomes and repeatability.
Open a GitHub issue or pull request with the exact section, proposed correction,
relevant qualifications/affiliation and declared conflicts of interest.

Recommendations receive a recorded disposition: accepted, accepted with scope,
needs evidence, rejected with reason or already resolved.
