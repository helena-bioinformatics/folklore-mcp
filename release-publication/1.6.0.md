Folklore 1.6.0 adds the public website's source-qualified gene profile workflow to the read-only MCP adapter.

- `resolve_gene` resolves symbols, aliases, previous symbols and stable identifiers without choosing ambiguous candidates.
- `get_gene_profile` reads the selected HGNC identity at an immutable reference snapshot.
- `get_gene_section` pages through thirteen source-qualified sections with preserved coverage, count units and source assertions.
- `search_gene_literature` retrieves a separate live, abstract-free literature capture, retaining match labels, capture identity, degradation and continuation.
- The existing seven tools, five workflow prompts and optional variant-evidence view remain available. All capabilities enabled expose eleven tools.

The standalone gene capability is opt-in through `FOLKLORE_PUBLIC_GENE_ENABLED=true`; gene literature additionally requires `FOLKLORE_LITERATURE_ENABLED=true`. The endpoint remains `https://api.helena.bio/folklore/v1/mcp`.

The public source suite passed 198 software tests; Ruff and formatting checks passed. These checks do not establish clinical or diagnostic accuracy. Immutable tag, Registry publication, GitHub Release assets and hosted acceptance are separate delivery evidence; preparation alone does not claim publication.

The adapter accepts public identifiers only, with no patient, phenotype narrative, family, segregation or private case context. Gene evidence and literature do not change variant classification or establish diagnosis or treatment. Keep source assertions separate and require qualified professional review.
