# Folklore MCP 2.0.0

- One hosted endpoint combines eleven anonymous scientific tools and eighteen
  authenticated case, source and result tools.
- Folklore API keys use the Authorization Bearer header. Invalid supplied
  credentials fail closed; authenticated catalogs and responses are private.
- Case processing preserves native account capabilities, limits, credit
  admission, explicit cost ceilings and durable command idempotency.
- Frozen JSON export queries preserve exact numeric values and strict schemas.
  Original downloads return a protected API URL with verified checksum and size.
- The public adapter remains Apache-2.0. Scientific authority implementations
  and private clinical data are outside this distribution.

The Registry identity and endpoint remain unchanged. A local Folklore server is
not required. Optional legacy client bridges remain independently versioned.
