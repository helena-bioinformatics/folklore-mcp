Folklore 1.5.0 adds source-linked gene-disease evidence to the public bioinformatics MCP server.

- `get_gene_disease_associations`: ClinGen Gene-Disease Validity assertions for an exact gene symbol or HGNC identifier.
- `search_disease_genes`: assertions matching an exact MONDO identifier or disease-name substring, retaining distinct diseases and source assessments.
- Existing variant interpretation, literature and support tools remain available. The full hosted configuration exposes seven tools.
- Gene-disease responses preserve inheritance, source links, snapshot provenance, coverage limits and bounded pagination. Empty results do not establish no association.
- Companion Agent Skill 1.4.0 and the separate 24-query English/Bulgarian genomic-discovery cohort are included. Existing 60/100 benchmark cases are unchanged; ranking improvement is not claimed.

The standalone gene-disease capability is opt-in through `FOLKLORE_GENE_DISEASE_ENABLED=true`. The hosted endpoint remains `https://api.helena.bio/folklore/v1/mcp`.

The public source test suite passed 103 tests, including regression coverage; Ruff and frozen Biorouter installation passed. Clinical or diagnostic accuracy is not established by these software tests.

This release exposes public evidence only. It does not accept patient histories, VCF or sequencing uploads, perform variant calling, run whole-genome pipelines or provide diagnoses. Results require qualified professional review. Initial gene-disease coverage is ClinGen Gene-Disease Validity, not every known association.
