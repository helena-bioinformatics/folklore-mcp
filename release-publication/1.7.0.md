Folklore MCP 1.7.0 names its germline classification tool `classify_germline_variant` and its VUS workflow prompt `assess_vus`.

- Classification responses retain normalized identity, automated ACMG/AMP class, reported criteria and source provenance in public output shape revision `2`.

- Client integrations and the Agent Skill use the current tool names, schemas and Streamable HTTP request metadata.

This release includes Agent Skill 1.7.0 and its checksum. The public adapter source is pinned by the signed `folklore-mcp-v1.7.0` tag.
